EVCP

충전기와 이용·결제·에너지 데이터를 하나로 연결해 AI로 장애와 수요를 예측하고 충전 운영을 최적화합니다.

개요핵심 기능서비스 구조레퍼런스적합한 곳
Overview

충전 데이터를 더 안정적이고 효율적인 운영으로 연결합니다

EVCP는 충전기 연결부터 회원·결제·관제까지 통합하고 AI 분석으로 장애 대응과 에너지 운영을 지원합니다.

충전기 통합 관리국제 충전 통신 표준(OCPP) 기반으로 서로 다른 충전기를 연결하고 상태와 설정을 원격 관리
AI 이상 징후 예측충전 상태와 오류 이력을 분석해 장애 가능성을 조기에 찾고 점검 우선순위를 안내
회원·결제·정산회원 관리와 충전 예약, 다양한 결제 수단, 이용 내역과 사업 정산 업무를 한곳에서 처리
수요·에너지 최적화시간·지역별 이용 패턴과 에너지 사용량을 분석해 운영 계획과 요금·부하 관리를 지원
AI Operations Console

충전 운영과 AI 분석을 한 화면에서 확인합니다

충전소·충전기 상태와 이용 데이터를 함께 분석해 장애 대응과 운영 최적화에 필요한 정보를 제공합니다.

Monitoring

충전소 통합 관제

운영 중인 충전소와 충전기 상태를 지도에서 확인하고, 상세 정보와 이용 이력을 바로 조회합니다.

  • 사업자·지역별 선택 사업자별·지역별 목록에서 운영 충전소 선택
  • 충전기별 상태·이력 충전기 상태와 최근 이용 이력을 한 화면에서 확인
  • 지도에서 직접 선택 원하는 충전소를 지도에서 바로 선택
Dashboard

운영 현황 대시보드

필요한 차트를 선택해 배치하고, 충전기 상태와 매출·충전량을 실시간으로 확인합니다.

  • 월별 매출 기간별 매출 추이 차트
  • 충전량 통계 월별 충전량 집계로 운영 규모 파악
  • 가동 충전기 수 지역별 충전가능·충전중·통신오류·고장 상태 집계
AI Insight

장애·수요·에너지 예측

충전 상태·오류 이력·이용 패턴·에너지 사용량을 AI로 분석해 운영자가 먼저 확인할 대상을 제안합니다.

  • 이상 징후 예측 반복 오류와 상태 변화를 분석해 장애 가능성이 높은 충전기 우선 점검
  • 충전 수요 예측 시간·요일·지역별 이용 패턴으로 예상 수요와 혼잡 구간 파악
  • 에너지 운영 권고 전력 사용량과 요금 조건을 고려해 부하 분산과 운영 시간 조정 지원
Event

실시간 이벤트 관제

충전기 상태 이벤트를 실시간으로 수집해 목록과 지도에 함께 표시하고, 상태 변경 시각까지 추적합니다.

  • 이벤트 실시간 표시 충전 시작·대기·연결 해제 등 상태 변경을 발생 순서대로 기록
  • 지도 기반 위치 확인 이벤트가 발생한 충전소 위치를 지도에 동시 표시
  • 상태 변경 이력 추적 충전기 아이디·충전소명·변경 시각 기록
Search

지도 기반 충전소 검색

로밍 제휴 충전소와 충전기의 상세 정보를 지도에서 검색합니다. 사용자 앱과 관리자 앱이 같은 지도 모듈을 사용합니다.

  • 충전소·충전기 상세 지도 기반 충전소·충전기 상세 정보 제공
  • 주소 기반 검색 주소로 충전소를 찾는 검색 기능
  • 운영기관·종류별 필터 운영기관·충전기 종류(완속·급속·초급속)별 필터링
Service Architecture

기능별 서비스를 분리해 장애 영향은 줄이고 확장은 쉽게 합니다
